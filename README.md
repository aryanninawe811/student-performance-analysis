📊 Student Performance Analysis System

A Python-based project that analyzes student marks, calculates academic performance, and generates visual reports using data analysis and visualization libraries.

🚀 Features

- Calculates student average marks.
- Assigns grades and determines pass/fail status.
- Compares Math, Science, and English marks.
- Generates subject-wise and student-wise bar charts.
- Exports student performance reports to CSV files.

🛠️ Technologies Used

- Python — Core programming
- Pandas — Data handling and analysis
- Matplotlib — Data visualization
- CSV — Student data storage and report generation

▶️ How to Run

1. Install Python 3.

2. Install the required libraries:
   
   pip install pandas matplotlib

3. Download or clone this repository.

4. Run the program:
   
   python main.py
